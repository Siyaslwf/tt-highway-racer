## ⚡ Overview
**Cyber-Outrun 2088** is a custom hardware-accelerated video game designed entirely in structural and behavioral Verilog. Rather than running on software or a CPU, this application executes via **pure hardware logic gates and registers**, performing real-time **beam racing** to output a crisp 640x480 60Hz VGA signal directly from manufactured silicon.

---

## ✨ Core Engineering Features
* **Zero Frame Buffer Architecture:** Pixel colors, road curvature, and traffic positioning are computed combinationally on-the-fly as the electron beam sweeps the monitor.
* **Velocity & Inertia Physics:** Smooth hardware-level acceleration up to 140 MPH Nitro speed and reactive braking dynamics.
* **Dynamic Headlight Projection:** Geometric lighting cones that illuminate the dark midnight asphalt ahead of your vehicle.
* **Vehicle Morphing System:** Instant hardware-level transformation between a Crimson Sports Car and a Neon Cyan Superbike.
