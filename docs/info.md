# Retro Highway Racer

## How it works
This chip generates a real-time 640x480 60Hz VGA arcade racing game using purely combinational and synchronous Verilog logic (racing the beam, no frame buffer). 
Features dynamic vehicle transformation between a Red Sports Car and a Cyan Motorcycle, pseudo-random oncoming traffic, road curb effects, and collision scoring.

## How to test
1. Connect a TinyVGA Pmod to the output port.
2. Connect input switches or Gamepad PMOD to the input port.
3. Use Switch 2 and 3 to steer Left and Right.
4. Toggle Switch 7 to transform between Car and Motorcycle.
5. Dodge oncoming traffic to keep your score high!
